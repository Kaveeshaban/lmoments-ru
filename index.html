L-моменты · распределение Пирсона III типа

L-моменты в анализе речного стока

Онлайн-расчёт параметров трёхпараметрического гамма-распределения (кривой Пирсона III типа) по рядам расходов воды методом L-моментов. Введите данные в указанном формате и сразу получите результаты.

Дугганна Ралалаге Кавиша Аширвадани Бандара · РГГМУ, Санкт-Петербург · магистратура, направление 05.04.05 «Прикладная гидрометеорология»

Что ввести
Ряды расходов воды в м³/с: один столбец на реку или створ
Что получить
L-моменты l1–l4, отношения t2–t4, параметры α, β, γ, среднее, σ, Cv, Cs
Где считается
В вашем браузере. Данные никуда не отправляются

Формат данных

Нужны два списка: названия рек и сами данные. Порядок названий должен совпадать с порядком столбцов с числами.

Названия (по одному в строке)

P.Sheltozerka - S.Sheltozero
Lososinka - R.Lososinka - G.Petrozavodsk
Neglinka - R.Neglinka - G.Petrozavodsk

Данные (расходы воды, м³/с)

1.31 6.02 0.72
1.45 5.06 0.70
1.05 4.14 0.47

Правила

  • Названия: одна река и створ в строке, пустые строки пропускаются.
  • Данные: только числа, без заголовков и названий. Столбцы разделяются пробелом или табуляцией.
  • Десятичный разделитель: точка или запятая.
  • Нулевые и отрицательные значения не учитываются.
  • Для каждой реки нужно не менее 4 значений. Ряды могут быть разной длины, но в первой строке данных должны быть значения для всех столбцов.
  • Пропуск в середине строки сдвигает следующие значения в соседний столбец, поэтому пустые клетки заполните или удалите строку целиком.
  • Если названий больше, чем столбцов, лишние названия не используются. Если столбцов больше, лишние столбцы игнорируются.

Расчёт онлайн

Вставьте названия и данные в поля ниже или откройте два текстовых файла. Результаты обновляются при вводе. Сейчас в полях учебный пример с условными данными, он показывает формат. Чтобы вернуть его, нажмите «Вернуть пример».

Класс риска наводнения определяется по L-коэффициенту вариации t2: меньше 0,2 — низкий, меньше 0,5 — умеренный, иначе высокий. Это упрощённое правило программы.

Метод

  
Ряд расходов упорядочен по возрастанию: x1 ≤ x2 ≤ … ≤ xn, суммы берутся по j = 1 … n. Порядок расчёта: вероятностно взвешенные моменты, L-моменты, их отношения, параметры распределения, обычные статистики.

  

    
Вероятностно взвешенные моменты

      
b0 = 1n Σ xj

      
b1 = 1n Σ j − 1n − 1 xj

      
b2 = 1n Σ (j − 1)(j − 2)(n − 1)(n − 2) xj

      
b3 = 1n Σ (j − 1)(j − 2)(j − 3)(n − 1)(n − 2)(n − 3) xj

    

    
L-моменты

      
λ1 = b0

      
λ2 = 2b1 − b0

      
λ3 = 6b2 − 6b1 + b0

      
λ4 = 20b3 − 30b2 + 12b1 − b0

    

    
Отношения L-моментов

      
τ2 = λ2λ1 (L-коэффициент вариации),   τ3 = λ3λ2 (L-асимметрия),   τ4 = λ4λ2 (L-эксцесс)

    

    
Параметр формы α при |τ3| < 1/3

      
z = 3πτ32

      
α = 1 + 0,2906zz + 0,1882z2 + 0,0442z3

    

    
Параметр формы α при 1/3 ≤ |τ3| < 1

      
z = 1 − |τ3|

      
α = 0,36067z − 0,59567z2 + 0,25361z31 − 2,78861z + 2,56096z2 − 0,77045z3

    

    
Ограничения на α

      
При |τ3| < 10−6 принимается α = 1000, при |τ3| ≥ 1 принимается α = 0,01.

      
Затем значение ограничивается интервалом 0,01 ≤ α ≤ 200.

    

    
Параметр масштаба β

      
β = λ2 √π Γ(α)Γ(α + ½)

    

    
Параметр положения γ

      
γ = λ1 − αβ

    

    
Обычные статистики

      
σ = β√α,   среднее = γ + αβ,   Cv = σсреднее,   Cs = 2√α

    

    
Класс риска наводнения

      
τ2 < 0,2 — низкий,   τ2 < 0,5 — умеренный,   иначе высокий

    

  

  
Отношение Γ(α) / Γ(α + ½) вычисляется через логарифм гамма-функции, поэтому расчёт устойчив и при очень больших α.
